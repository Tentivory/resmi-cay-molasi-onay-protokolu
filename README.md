# Resmi Çay Molası Onay Protokolü

## Dünyanın En Ciddi ve En Gereksiz Yazılımı

Bu repository, Türkiye Cumhuriyeti'nin en önemli sorunlarından biri olan **çay molası taleplerinin resmi onay süreci**ni çözmek için geliştirilmiştir.

### Neden Var?

Çünkü insanlar çay içmek istiyor ama bürokrasi "Hayır" diyor. Bu script, o "Hayır"ı veya "Evet"i **abartılı resmi dil** ile söylüyor. Çalışıyor. Gerçekten.

### Nasıl Kullanılır?

```bash
python cay_molasi.py
```

Adınızı ve süreyi girin. Karar çıksın. Çayınız demlensin veya demlenmesin. Kader.

### Özellikler

- Rastgele bürokratik sebepler
- Ciddi görünen ama komik kararlar
- Çay stoklarını devlet sırrı ilan etme yetkisi
- Kedi geçtiği için onay

### Uyarı

Bu yazılımı kullanmak çay içmenizi garantilemez. Bürokrasi kazanır.
